# Лабораторная работа №2: Структуры в языке C

## Описание работы
Изучение объявления и использования структур, вложенных структур, указателей на структуры, массивов структур, передачи структур в функции, перечислений (enum) и объединений (union).

## Задания

### Задание 1. Базовая структура
Создание структуры `Student` с полями: имя, возраст, средний балл. Реализованы:
- объявление переменной структуры
- заполнение значениями
- вывод данных
- ввод с клавиатуры

### Задание 2. Массив структур
- создание массива из 5 структур `Student`
- заполнение данными
- вывод всех студентов
- поиск студента с максимальным средним баллом

### Задание 3. Вложенные структуры
Создание структур `Date` и `Person`:
- заполнение структуры
- вывод данных
- вывод людей, родившихся после 2000 года

### Задание 4. Структуры и функции
Создание структуры `Rectangle` с функциями:
- вычисление площади (передача по значению и по указателю)
- вычисление периметра (передача по значению и по указателю)

### Задание 5. Перечисления (enum)
- создание перечисления `Day` (дни недели)
- использование `switch` для вывода значения
- использование `enum` внутри структуры

### Задание 6. Объединения (union)
- создание объединения `Data` (int, float, char)
- демонстрация хранения одного значения
- создание структуры с union и полем-индикатором типа

### Задание 7. Комплексное задание
Создание структуры `Student` с полями: имя, возраст, курс (enum), средний балл.
Реализованы функции:
- добавление студента
- вывод списка
- поиск по имени
- сортировка по среднему баллу

## Используемые технологии и библиотеки

- **Язык программирования:** C
- **Стандартная библиотека:** stdio.h (только)
- **Компилятор:** GCC
