Лабораторная работа 3
Динамические массивы в языке C

Цель работы: изучить работу с динамической памятью: функции malloc, calloc, realloc,
free, создание и использование динамических массивов.

Теория:
Обычный массив объявляется так:
int arr[10];
В этом случае размер массива фиксирован и не может быть изменен.
Динамический массив создается с помощью указателя и функции выделения памяти:
int *arr;
arr = malloc(10 * sizeof(int));
После этого с arr можно работать как с обычным массивом.
Динамические массивы используются в следующих случаях:
• когда размер массива заранее неизвестен
• когда размер массива нужно менять во время работы программы
• когда требуется эффективно использовать память
Динамический массив — это указатель на первый элемент массива.
Доступ к элементам осуществляется так же, как и в обычном массиве: arr[i] или через
указатель: *(arr + i)
Функции работы с динамической памятью
Для работы с динамической памятью используется библиотека stdlib.h.
Функция malloc - выделяет заданное количество байт памяти.
Синтаксис:
pointer = (type*)malloc(size);
Пример:
int arr = (int)malloc(n * sizeof(int));
Особенности:
• выделяет память без инициализации
• значения в памяти случайные
• при ошибке возвращает NULL
Функция calloc - выделяет память и инициализирует её нулями.
Синтаксис:
pointer = (type*)calloc(count, size);
Пример:
int arr = (int)calloc(n, sizeof(int));

Особенности:
• все элементы равны 0
• принимает два аргумента: количество элементов и размер одного элемента
• работает медленнее malloc
Различие между malloc и calloc
malloc:
• не инициализирует память
• принимает один аргумент
calloc:
• заполняет память нулями
• принимает два аргумента
Функция realloc - изменяет размер ранее выделенного блока памяти.

Синтаксис:
pointer = (type*)realloc(pointer, new_size);
Пример:
arr = (int*)realloc(arr, m * sizeof(int));
Особенности:
• может изменить адрес блока памяти
• сохраняет старые данные (в пределах нового размера)
• новые элементы не инициализируются
• при ошибке может вернуть NULL
Функция free - освобождает ранее выделенную память.

Синтаксис:
free(pointer);
После вызова free память становится доступной для повторного использования.
Правила работы с динамической памятью
1. Каждому вызову malloc, calloc или realloc должен соответствовать вызов free
2. После освобождения памяти указатель желательно обнулить:
free(arr);
arr = NULL;
3. Нельзя использовать память после её освобождения
Пример ошибки:
free(arr);
arr[0] = 10;
4. Нельзя освобождать одну и ту же память дважды
5. Всегда проверять результат malloc, calloc и realloc
Пример:
if (arr == NULL) {
ошибка обработки памяти
}
Утечка памяти возникает, если выделенная память не освобождается.
Пример:
int *arr = malloc(100 * sizeof(int));
Если free не вызван, память остается занятой до завершения программы.
Висячий указатель — это указатель, который указывает на уже освобожденную память.
Пример:
int *arr = malloc(10 * sizeof(int));
free(arr);
После этого arr содержит адрес, но использовать его нельзя.
Двойное освобождение памяти
Ошибка возникает, если вызвать free для одного и того же указателя дважды.
Пример:
free(arr);
free(arr);
Изменение размера массива
Размер динамического массива можно изменять с помощью realloc.
При увеличении массива новые элементы не инициализируются.
При уменьшении часть данных теряется.
Двумерные динамические массивы
Двумерный массив реализуется как указатель на указатель.
Пример объявления:
int **matrix;
Сначала выделяется память под массив указателей (строки), затем для каждой строки
выделяется память под элементы.
Отличие статических и динамических массивов
Статические массивы:
• имеют фиксированный размер
• создаются при запуске программы
• автоматически освобождаются
Динамические массивы:
• размер задается во время выполнения
• требуют ручного управления памятью
• могут изменять размер
Когда использовать динамические массивы
• когда размер данных неизвестен заранее
• когда требуется изменять размер массива
• при работе с большими объемами данных
Краткий итог
malloc — выделяет память
calloc — выделяет и заполняет нулями
realloc — изменяет размер
free — освобождает память
Программист обязан управлять памятью вручную и избегать ошибок, связанных с
утечками и неправильным использованием указателей.

Ещё немного информации:
1. Опасность realloc
Нельзя сразу перезаписывать указатель:
arr = realloc(arr, new_size);
Если realloc вернёт NULL → старый адрес потеряется → утечка памяти.
Правильно:
int *tmp = realloc(arr, new_size);
if (tmp != NULL) {
arr = tmp;
}
2. sizeof — зачем он нужен
Нужно так:
malloc(n * sizeof(int))
А не так:
malloc(n * 4) // плохо
Почему:
• размер типов может отличаться на разных системах
• sizeof делает код переносимым
3. realloc и уменьшение массива
• при уменьшении массива данные "обрезаются"
• восстановить их нельзя
4. realloc(NULL, size)
Это полезный факт:
int *arr = realloc(NULL, n * sizeof(int));
Работает как malloc
5. Утечка через потерю указателя
int *arr = malloc(10 * sizeof(int));
arr = malloc(20 * sizeof(int)); // утечка!
Старый блок потерян → его нельзя освободить
