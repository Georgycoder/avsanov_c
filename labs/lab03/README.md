# Лабораторная работа №3: Динамические массивы в языке C

## Описание работы
Изучение работы с динамической памятью: функции malloc, calloc, realloc, free, создание и использование динамических массивов.

## Задания

### 1.c - Создание динамического массива (malloc)
- Запрос размера у пользователя
- Выделение памяти через malloc
- Заполнение и вывод массива

### 2.c - Использование calloc
- Выделение памяти через calloc
- Демонстрация обнуления всех элементов

### 3.c - Поиск элементов
- Поиск максимального элемента
- Поиск минимального элемента
- Вычисление суммы элементов

### 4.c - Изменение размера (realloc)
- Увеличение массива через realloc
- Добавление новых элементов
- Уменьшение массива

### 5.c - Удаление элемента
- Удаление элемента по индексу
- Сдвиг элементов
- Уменьшение размера через realloc

### 6.c - Вставка элемента
- Вставка элемента в заданную позицию
- Увеличение размера массива
- Сдвиг элементов

### 7.c - Массив структур (динамический)
- Структура Student (имя, возраст)
- Динамический массив структур
- Поиск самого старшего студента

### 8.c - Динамический список чисел
- Меню с выбором действий
- Добавление элемента
- Удаление элемента по индексу
- Вывод списка

## Используемые библиотеки
- stdio.h - ввод/вывод
- stdlib.h - malloc, calloc, realloc, free
