# Лабораторная работа №4: Ввод-вывод и работа с файлами в языке C

## Описание работы
Освоение работы с файлами: открытие и закрытие потоков, чтение и запись текстовых и бинарных данных, форматированный ввод-вывод, перемещение по файлу.

## Используемые технологии и библиотеки
- Язык программирования: C
- Стандартная библиотека: stdio.h
- Компилятор: GCC

- ## Описание заданий

### Задание 1. Открытие и закрытие файла
1. Открыть файл "test.txt" в режиме записи
2. Проверить, что файл успешно открылся
3. Вывести сообщение об ошибке при неудаче
4. Закрыть файл

### Задание 2. Посимвольная запись и чтение
1. Записать в файл несколько символов с помощью putc
2. Закрыть файл
3. Открыть файл для чтения
4. Считать файл посимвольно с помощью getc
5. Вывести содержимое на экран

### Задание 3. Работа со строками
1. Записать несколько строк в файл с помощью fputs
2. Открыть файл для чтения
3. Считать строки с помощью fgets
4. Вывести их на экран

### Задание 4. Форматированный ввод-вывод в файл
1. Записать в файл несколько чисел и строк с помощью fprintf
2. Закрыть файл
3. Открыть файл для чтения
4. Считать данные с помощью fscanf
5. Вывести считанные значения

### Задание 5. Ввод с клавиатуры и запись в файл
1. Считать строку с клавиатуры с помощью fgets
2. Записать её в файл
3. Вывести содержимое файла на экран

### Задание 6. Бинарные файлы (простые данные)
1. Создать массив целых чисел
2. Записать его в бинарный файл с помощью fwrite
3. Считать массив обратно с помощью fread
4. Вывести данные

### Задание 7. Работа со структурами в бинарных файлах
Структура Person: имя, возраст
1. Создать одну структуру
2. Записать её в файл
3. Считать обратно
4. Вывести данные

### Задание 8. Массив структур
1. Создать массив структур Person
2. Записать массив в бинарный файл
3. Считать массив обратно
4. Вывести все элементы

### Задание 9. Позиционирование в файле
1. Открыть файл
2. Переместиться к заданной позиции с помощью fseek
3. Считать данные начиная с этой позиции
4. Вывести результат

### Задание 10. Размер файла
1. Открыть файл
2. Определить размер файла с помощью fseek и ftell
3. Вывести размер

### Задание 11. Проверка конца файла и ошибок
1. Читать файл до конца
2. Проверить достижение конца файла с помощью feof
3. Проверить наличие ошибок с помощью ferror

### Задание 12. Простая файловая база людей
Структура Person: имя, возраст
1. Ввод данных с клавиатуры
2. Запись данных в бинарный файл
3. Чтение всех записей из файла
4. Вывод на экран
5. Использовать fread и fwrite
6. Проверять открытие файла
7. Закрывать файл после работы
