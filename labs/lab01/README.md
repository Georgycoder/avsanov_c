# Лабораторная работа №1: Типы данных, память и выражения в C

## Задание
Изучение базовых типов данных языка C, работа с переменными, операциями, вводом/выводом, а также исследование особенностей представления данных в памяти.

## Что делает программа
Программа состоит из 14hf файлов, каждый из которых решает отдельную задачу:
1. **task01.c** - объявление и вывод переменных разных типов
2. **task02.c** - вывод размеров типов данных (sizeof)
3. **task03.c** - вывод значений и адресов переменных
4. **task04.c** - вычисление остатка от деления
5. **task05.c** - демонстрация инкремента и декремента
6. **task06.c** - преобразование типов при делении
7. **task07.c** - демонстрация потери точности float
8. **task08.c** - переполнение целочисленной переменной
9. **task09.c** - вычисление математических выражений
10. **task10.c** - обмен значений переменных
11. **task11.c** - выделение последней цифры числа
12. **task12.c** - разложение числа на сотни, десятки, единицы
13. **task13.c** - перевод секунд в формат HH:MM:SS
14. **task14.c** - исследование расположения переменных в памяти

## Используемые технологии
Язык программирования: C
Стандартная библиотека: stdio.h, limits.h
Компилятор: GCC

## Библиотеки
`stdio.h` - для ввода/вывода (printf, scanf)
`limits.h` - для получения максимального значения int (INT_MAX)
